# 구현할 기능 목록 정리

## 숫자 생성
- [x] `숫자 야구 게임을 시작합니다.` 을 출력한다.
- [x] 1~9까지 임의의 정답 숫자를 3개 생성한다
    - [x] 매번 생성할 때 마다 중복 여부를 확인한다.

## 입력

- [x] 3자리 수를 입력받는다
    - [x] 1~9의 숫자가 아니라면 예외
    - [x] 숫자가 중복이라면 예외
    - [x] 3자리가 아니라면 예외

- [ ] 종료 및 재시작을 위한 숫자를 입력받는다
    - [ ] 새로 시작하려면 1을, 종료 하려면 2를 입력 받는다.
    - [ ] 1 또는 2 가 아니라면 에외

## 정답 비교

- [x]
    - [x] 자리와 숫자가 일치하면 스트라이크
    - [x] 숫자만 일치하면 볼
    - [x] 하나도 일치하지 않는다면 낫싱

- [x] 3개의 숫자를 모두 맞췄다면 재시작 문구를 출력한다.


## 정해지지 않은 부분
- 리드미를 적을때 설계까지 정해야 할까
- 클래스까지 미리 정해야되는가
